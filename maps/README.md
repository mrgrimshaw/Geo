# Worth Discovery: shared maps (test)

`worth-thelon-tenure.rgis`: RustGIS project, Thelon AOI tenure (Nunavut and NWT).
Open: https://web.rustgis.app/?project=https://raw.githubusercontent.com/mrgrimshaw/Geo/main/maps/worth-thelon-tenure.rgis

Layers read live from public services when opened (no tenure data is stored here):
- Nunavut: CIRNAC/ISC open data, Open Government Licence - Canada
- NWT: GNWT Mining Recorder's Office (terms: no modification or redistribution without permission)
